# 3.1 设置

1. 触摸菜单 `[F2: 系统] - 2: 控制参数 - 9: 网络 - 2: 服务 - 3: NTP 客户端 ([F2: system] - 2: Control parameters - 9: Network - 2: Service - 3: NTP client)`

2. 设置 NTP 时间同步所需的每个参数。

3. 您可以通过触摸“立即执行”按钮进行 NTP 时间同步。

* 是否使用 NTP 客户端 : '禁用'
